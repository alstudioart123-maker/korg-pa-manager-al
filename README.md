# KORG PA MANAGER ULTIMATE

Program për analizimin dhe organizimin e SET-eve Korg PA4X dhe PA3X.

- Ndërfaqe në shqip
- Analizim i strukturës SET
- Menaxhim i Styles, Sounds, Performances, Pads dhe PCM
- Kontroll për përputhshmëri PA4X -> PA3X

Konvertimi real do të implementohet gradualisht dhe do të
testohet me kopje të SET-eve origjinale.
