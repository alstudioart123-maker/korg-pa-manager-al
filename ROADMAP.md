# KORG PA MANAGER ULTIMATE

## Qellimi
Aplikacion Windows per menaxhimin e formateve Korg Pa,
luajtjen e STYLE-ve dhe perdorimin e mostrave origjinale.

## Modulet
- formats: lexim dhe shkrim i formateve SET
- styles: evente, variacione, intro, fill, break, ending
- samples: PCM, multisamples dhe harta notash
- audio: luajtje, miksim dhe perpunim audio
- midi: hyrje MIDI dhe njohje akordesh
- models: profile dhe perputhshmeri sipas modelit
- ui: nderfaqja grafike

## Faza
1. Analizues SET dhe inventar skedaresh
2. Profilet e modeleve Korg
3. Lexuesi i eventeve STYLE
4. Motori MIDI dhe luajtja e STYLE-ve
5. Motori i mostrave dhe luajtja audio
6. Menaxhimi i tingujve, Pads dhe SongBook
7. Konvertimi dhe eksporti i verifikuar
8. Paketimi per Windows

Asnje konvertim nuk konsiderohet i sakte pa testim.
Skedaret origjinale nuk modifikohen gjate analizimit.
